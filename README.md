# pea-manager-skill
A claude code skill to manage your french PEA.

## Dependencies
This skill relies on several MCP tools like yfinance or EODHD MCP server on claude.

### EODHD server
The EODHD MCP server repo is located at [EODHD](/home/yann/software/finance/EODHD-MCP-Server) from the [documentation](https://github.com/EodHistoricalData/EODHD-MCP-Server).
To update the repository run:

```bash
git fetch origin
git merge origin/main
```

or

```bash
git pull origin main
```
